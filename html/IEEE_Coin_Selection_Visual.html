Abstract

This paper introduces a fast, adaptive coin selection algorithm optimized for UTXO-based blockchains like Bitcoin. The approach leverages random sampling and intelligent filtering to produce low-fee, scalable, and wallet-friendly transactions. Benchmarks demonstrate up to 10x speed improvements and 15–25% fee reductions over traditional algorithms.

Algorithm Diagram

Pseudocode

function selectUTXOs(utxos, target):
    if target in [u.amount for u in utxos]:
        return [u]
    if sum(u.amount for u in utxos) == target:
        return utxos
    if sum(u.amount for u in utxos) < target:
        return []

    best = None
    for i in range(1000):
        shuffle(utxos)
        selected, total = [], 0
        while total < target:
            u = random choice
            selected.append(u)
            total += u.amount
        if better(selected, best):
            best = selected
    return clean(best, target)

Conclusion

The adaptive coin selection algorithm balances speed and fee optimization through randomized selection and heuristic filtering. It outperforms Greedy, BnB, and Knapsack methods in speed and practical scalability, and has been successfully deployed in production within the Xapa Wallet system.
